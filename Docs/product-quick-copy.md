# 상품 정보 빠른 복사 #5

후르츠패밀리 우선, Instagram 후속 비교. 기준 브랜치 `feat/4-export-channel-links`에서 `feat/5-product-quick-copy`로 분기했다.

## 실행

앱 첫 화면 → 상품 정보 빠른 복사. 본 앱에서 제품명/설명/브랜드/실측 전체와 가격/총장/허리/허벅지를 각각 복사할 수 있다. 샘플은 사용자가 제공한 LEVI'S 상품이며 후르츠 56,000원, Instagram 기본 65,000원/팔로우 55,000원을 구분한다. 문단·원문 오탈자·태그를 유지한다.

Dynamic Island 복사 도우미에서 채널과 모드를 선택하고 시작한다. 세션 중에는 상품과 채널이 고정된다. 변경하려면 종료 후 다시 시작한다. 본 앱과 QuickCopyWidget 타깃의 서명 팀은 Xcode에서 동일하게 설정해야 한다. 현재 최소 iOS는 26.4다.

## 세 가지 모드

| 모드 | 동작 | 판정 |
|---|---|---|
| 직접 복사 실험 | LiveActivityIntent가 본 앱 프로세스에서 쓰기 시도 | 후르츠를 유지한 채 실제 새 값이 붙는지 기기 검증 필요 |
| 앱에서 복사·직접 복귀 | Island 링크 → 본 앱 활성화 → 복사 → 사용자가 후르츠로 전환 | 백그라운드 쓰기와 분리한 비교군 |
| 앱에서 복사·서비스 링크 열기 | 활성화 후 복사 → 고정된 서비스 홈페이지 링크 요청 | 기존 작성 화면·로그인·초안 유지 보장 없음 |

외부 링크는 Universal Link 처리나 기본 브라우저 설정에 따라 앱 또는 웹으로 열린다. 후르츠 등록 화면으로 직접 진입한다고 가정하지 않는다. 네이버/Cafe24는 이번 우선 구현 범위가 아니다.

## 디자인

펼친 Island와 잠금 화면에 제품명/설명/브랜드/실측 2×2 패널. 어두운 버튼과 주황 아이콘, 앱 이름과 활성 상태 점. 작은 Island는 아이콘과 복사 표시. 시스템이 외곽 크기와 확장을 제어한다. 확장·작은 Island·잠금 화면 Xcode 프리뷰를 제공한다.

실측 전체는 `총장 59 cm\n허리 단면 43 cm\n허벅지 단면 32 cm` 한 문자열이다. 세 입력란 자동 분배 기능이 아니다. 후르츠 개별 폼에는 본 앱의 `59`, `43`, `32` 버튼을 사용한다.

## 상태와 제한

- 세션은 본 앱 저장소에 보관하며 8시간 이후 만료된다. 해당 활동이 실제로 활성/오래된 상태인지도 확인한다.
- 종료·교체된 세션의 버튼 요청은 거절한다. 새 세션 시작 전 기존 활동을 종료한다.
- 앱 경유 요청은 세션 UUID와 네 가지 필드만 허용한다. 임의 외부 URL이나 복사 텍스트를 링크에서 받지 않는다.
- 동일 요청의 2초 이내 연속 실행을 억제한다. 활성화 알림 반복으로 같은 요청을 재실행하지 않는다.
- `localOnly`로 기기 간 전달을 제한하며 외부 클립보드를 자동으로 읽지 않는다.
- 쓰기 API 호출은 외부 수신 성공 응답이 아니다. 직접 모드 상태는 ‘시도’로 표시한다.
- 앱 종료 시에도 저장된 세션을 조회하지만 OS의 Live Activity 실행·백그라운드 제한은 실제 기기에서 확인해야 한다.
- LiveActivityIntent는 본 앱 프로세스에서 실행한다. 위젯은 Activity 상태를 표시하며 세션/기록 저장소를 직접 읽지 않으므로 App Group을 사용하지 않는다.
- 이번 브랜치는 빠른 복사 #5 범위다. 이전 대화의 실험 파일은 분기 시 작업 트리에 없었으며 전체 웹뷰 실험을 다시 포함하지 않았다.

## 기기 검증 순서

1. BASELINE을 복사한 후 후르츠 등록 화면을 준비한다.
2. 직접 복사 모드에서 Island를 펼쳐 제품명/브랜드/설명/실측을 번갈아 누른다.
3. 실제 입력값이 BASELINE이나 이전 값이 아니라 이번 값인지 확인한다. 붙여넣기 의도 확인 팝업 여부도 기록한다.
4. 앱 경유·직접 복귀 모드로 반복한다. 앱 실행 중/종료 후/잠금 해제 후를 나눠 확인한다.
5. 서비스 링크 열기 모드로 반복하고 홈 이동, 기존 작성 화면, 새 탭, 로그인과 초안 유지를 기록한다.
6. 개별 가격 및 세 실측 숫자를 복사해 전체 문자열 복사와 비교한다.
7. 상품 설명의 빈 줄·이모지·계정명·태그·가격을 확인한다.
8. 종료된 활동, 오래된 링크, 반복 탭, 다른 앱에서 클립보드 덮어쓰기, 큰 글씨, Island 없는 기기의 잠금 화면을 확인한다.
9. 결과 화면에 실행 방식·실제 값·화면·초안·로그인·이동 횟수를 저장한다. 미기록은 미검증이다.

기록은 최대 300건을 기기에 저장한다. 보고서 복사는 기존 클립보드를 교체한다. 삭제는 기록만 지우며 활동이나 클립보드를 변경하지 않는다. 민감한 계정 정보를 기록하지 않는다.
