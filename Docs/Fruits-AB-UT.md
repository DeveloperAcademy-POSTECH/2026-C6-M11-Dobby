# 후루츠 내보내기 A/B 실기기 확인

- A: 제품 상세 페이지에서 항목별 복사. Live Activity를 시작하지 않는다.
- B: Live Activity 시작 후 후루츠로 이동. 아일랜드에서 복사하면 Dobby를 거쳐 후루츠로 돌아온다.
- 체크 표시는 등록 완료가 아니라 해당 방식에서 후루츠 앱 열기가 성공했음을 뜻한다. A/B 각각 기록하며 내보내기 화면 세션 동안 유지한다.

## 확인 순서

1. A 진입 후 상품명·설명·브랜드·가격을 메모에 붙여넣어 확인한다. 설명의 줄바꿈도 확인한다.
2. 실측은 cm 없이 숫자만 복사되는지 확인한다. 빈 항목의 복사는 비활성화된다.
3. A에서 후루츠를 열고 돌아오면 상세 페이지를 유지하는지 확인한다.
4. B에서 후루츠를 열고 아일랜드 상품명 복사 → 자동 복귀 → 붙여넣기를 확인한다.
5. B 사용 후 A로 전환하면 기존 Live Activity가 종료되는지 확인한다.
6. 실시간 현황을 끈 상태에서 B의 오류 안내와 재시도를 확인한다.
7. 후루츠 앱 연결 실패 시 안내가 표시되고 성공 체크가 생기지 않는지 확인한다.

## 현재 데이터 범위

현재 앱 진입점은 기존 LEVI'S 샘플을 사용한다. 사진이 없으면 자리 표시 이미지를 보여준다.
실측은 기본적으로 총장·허리·허벅지를 제공한다. 상의/하의별 상세 항목은
`ExportProduct.detailMeasurements`에 `Garment.orderedMeasurements.map(ExportMeasurement.init(measuredValue:))`로 전달할 수 있다.
없는 사진·실측값을 샘플로 채우지 않는다. 촬영 결과의 상품 상세 연결과 편집 화면은 별도 연동 범위다.
