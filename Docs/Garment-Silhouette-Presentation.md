# 옷 윤곽 표시 · 애니메이션 개선 · 2026-10-01

## 화면 동작

옷을 인식하면 테두리와 20% 반투명 채움이 짧게 나타난다. 같은 옷의 작은 변화는 **0.22초 ease-in-out**으로 이어진다. 인식 안내는 배경색만 0.20초 전환하고 문구·아이콘·크기는 즉시 바꿔 글자가 겹치지 않게 한다. 셔터는 짧은 투명도 전환과 0.97배 눌림을 사용하며 반복 확대나 튀는 spring 효과는 사용하지 않는다.

윤곽이 크게 바뀌거나 구멍·영역 수가 달라지면 완성된 두 윤곽을 **0.16초 페이드**로 교체한다. 기존 경로 전환 도중 새 결과가 들어와도 현재 표시 상태에서 이어진다. 회전·인식 해제·분석 만료·화면 이탈은 오래된 윤곽과 애니메이션을 즉시 제거한다.

**동작 줄이기** 설정에서는 윤곽의 이동 보간과 버튼 크기 변화를 사용하지 않는다. 새 윤곽은 짧은 0.10초 페이드로 표시하며, 설정이 켜지면 진행 중인 경로 전환을 즉시 멈춘다.

## 표시선 다듬기

- 기존 픽셀 경계 추적 결과에 표시 전용 단순화와 제한된 모서리 곡선을 적용한다.
- 비스듬한 소매와 바지 인심의 계단 모양을 줄이도록 단순화 허용치를 1.25~1.7 마스크 픽셀에서 적응적으로 선택한다. 모서리 다듬기는 최대 0.3 픽셀이며 전체 표시 이동 예산은 **최대 2 마스크 픽셀**이다. cm 단위 정확도를 의미하지 않는다. 용량에 들어간다는 이유만으로 한 픽셀 계단 모양을 남기지 않는다.
- 각 닫힌 윤곽을 128점으로 만들되 단순화 후의 모서리를 필수점으로 유지한다. 목·겨드랑이·소매의 굴곡이 균등 간격 샘플 사이에서 사라지는 것을 피한다.
- 구멍과 분리된 영역을 유지하고 even-odd 채움으로 구멍을 투명하게 남긴다. 방향·포함 관계·자기 교차를 검사한다.
- 작은 변화의 단일 외곽만 시작점을 맞춰 보간한다. 면적·중심·점 이동을 제한하고 25%·50%·75% 중간 모양의 교차를 검사한다. 이 검사는 연속 보간 전체에 대한 수학적 보증은 아니다.
- 최대 16개 윤곽이나 작업 예산을 넘으면 일부 영역을 버리지 않는다. 총 4,096점 이하의 원래 경계로 대체하여 페이드하고, 그보다 복잡하면 표시를 생략한다.

원래 RGB 좌표, 이진 측정 마스크, 모델 점, 깊이, 촬영 준비 조건, 저장된 실측 결과에는 표시용 단순화나 애니메이션을 적용하지 않는다. 시각적으로 부드러운 윤곽이 더 높은 인식·cm 정확도를 보증하지 않는다.

## iOS 렌더링과 처리량

경계 생성과 대응점 계산은 UI actor 밖에서 처리한다. 실제 작업은 하나만 실행하고 대기 중에는 최신 결과 하나만 남긴다. 취소·회전 전의 작업이 늦게 완료되어도 이전 윤곽이 다시 나타나지 않도록 세대와 결과 ID를 확인한다.

여러 구멍이나 분리된 영역은 바깥 사각형이 겹치는 경우에만 서로의 선분을 비교한다. 닿거나 포함된 영역은 기존 교차 검사를 유지하여 형태 보존 조건을 바꾸지 않고 불필요한 비교를 줄인다.

최대 두 개의 `CAShapeLayer`와 [Core Animation의 CABasicAnimation](https://developer.apple.com/documentation/quartzcore/cabasicanimation)을 사용한다. Swift에서 매 화면 프레임의 점 좌표를 다시 계산하는 타이머는 없다. 미리보기의 렌더링 목표는 기존 30fps에서 60fps로 올렸으며, 모델 분석 간격은 0.35초로 유지한다. 목표값은 실제 기기의 지속 FPS·발열·배터리 결과를 의미하지 않는다.

화면 크기나 좌표 변환이 바뀌면 현재 화면 좌표로 즉시 다시 배치한다. ARKit의 실제 display transform을 사용해 영상의 방향과 aspect-fill 잘림에 맞춘다. [iOS 동작 줄이기 설정](https://developer.apple.com/documentation/uikit/uiaccessibility/isreducemotionenabled) 변경도 즉시 반영한다.

## 검증

- 전체 Core 테스트 **325개 통과**, 실패 0. 표시 전용 13개에는 반팔·긴팔의 비스듬한 경계, 목·겨드랑이 보존, 한 픽셀 구멍, 분리 영역, 네 방향 회전, 표시 이동 예산과 보간 거부 조건을 포함한다. 실제 합성 미리보기의 400×500 상의·하의 다각형도 재현해 소매·인심 선의 방향과 큰 모서리 수를 확인한다.
- 기존 측정 마스크와 정확한 경계 추출 결과가 유지되는 것을 검사했다.
- 영역 사각형 비교 최적화 전후의 일반 옷·16개 윤곽·한 픽셀 구멍 경로도 좌표가 완전히 동일했다. 동일성 결과를 측정 보고서에 함께 보관했다.
- iPhone 17 Pro / iOS 26.4 시뮬레이터에서 UI 8개와 실제 UIWindow/CALayer 표시 9개, **서로 다른 17개 테스트 통과**. 경로 전환, 구멍 교체, 회전·크기 변경·취소·화면 제거, 대기 중 동작 줄이기 변경을 검사했다. 마지막 교차 검사 최적화 후 Core 325개·표시 9개·기기용 빌드를 다시 확인했다.
- 상의·하의·가로 화면 캡처에서 사선의 계단 모양 제거와 안내 문구 비중첩을 눈으로 확인했다. 합성 미리보기이며 실제 카메라 인식 정확도 검증은 아니다.
- 최종 iOS 기기용 빌드 성공 (`CODE_SIGNING_ALLOWED=NO`). 실기기 설치·카메라 촬영 확인은 별도다.
