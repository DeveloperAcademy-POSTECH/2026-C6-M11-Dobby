# 깊이 평면 계산 개선 기록 (#213)

설정의 깊이 평면 테스터와 전용 화면·UI 테스트는 실험 후 제거했습니다. 몸판 중심 평면 계산, 코어 진단 자료 구조와 회귀 테스트는 유지합니다. 이 문서의 테스터 관련 내용은 개발 중 사용한 검증 방식의 기록입니다.

## 계산 연결

`GarmentPlaneDiagnostics.analyze`는 `GarmentPlaneGeometry.fitDetailed`에 동기 observer만 추가해 같은 함수를 실행합니다. 표본 위치/순서, 난수 시드, 현재 1,024회 후보 탐색과 지지율을 보존하는 TLS 보정을 공유합니다. 진단 observer 자체는 결과를 바꾸지 않습니다. 10mm/75% 및 기존 품질 검증은 유지합니다. observer를 쓰지 않는 기존 실측은 진단용 표본 배열을 생성하지 않습니다.

현재 앱의 계산 코드로 재분석하므로 과거 버전의 결과와 다를 수 있습니다. 화면에 저장 당시 오류와 현재 재분석 단계를 함께 표시합니다.

## 검증 기록

- 합성 깊이: 정상 평면의 품질/결과 동일, 두 높이 평면의 최초 RANSAC 탈락, 깊이 NaN·낮은 신뢰도·잘못된 버퍼, JSON 직렬화.
- 원본 회색 코트 재실행: `814C3ABC`는 첫 RANSAC에서 481/574(유효765개), `6CA25440`는 같은 단계에서 649/782(유효1042개). 저장된 오류 수치를 재현했습니다.
- 정상 기록 `B58E5F87`: 699/547(유효729개), 평면 확정.
- 사용자 원본 기록은 저장소에 포함하지 않습니다. 개발 중 회색 코트 기록을 설치한 시뮬레이터로 화면을 검증했으며, 해당 전용 UI 테스트는 테스터 화면 제거와 함께 삭제했습니다. 코어 계산 회귀 테스트는 유지합니다.

## 평면 계산 v3 비교 실험

- 후보 탐색을128회에서1,024회로 늘렸습니다.
- 첫 TLS를 포함한 모든 보정에서 일치 표본 수가 줄면 이전 후보를 유지합니다. 수가 같을 때에는 제곱 잔차가 증가하지 않을 때만 채택합니다.
- 보정하지 않은 후보를 유지해도 공간 분포·가로세로 범위·RMS≤8mm·시야각을 모두 검사합니다.
- 버전은 `garment-plane-3`, 결과 엔진은 `garment-plane-neck-perpendicular-mask-3` / `garment-plane-left-neck-vertical-hem-mask-2`로 구분합니다. 옛 기록을 덮어쓰지 않습니다.
- 테스터/진단 JSON에는 탐색 횟수, 최초 일치 수, 보정 전후 일치 수와 채택 여부가 추가됩니다.

| 데이터 | v2 일치/필요 | v3 일치/필요 | v3 결과 |
|---|---:|---:|---|
| 20DE8888 표본617개 | 448/463 | 465/463 | 표본 이후 평면 검사 통과; 보정465→460은 거절 |
| 814C3ABC 전체 기록 | 481/574 | 493/574 | 여전히 첫 후보 검사 실패 |
| 6CA25440 전체 기록 | 649/782 | 697/782 | 여전히 첫 후보 검사 실패 |
| B58E5F87 전체 기록 | 699/547 | 719/547 | 평면 통과, 기존 치수 계산 유지 |

20DE8888은 사용자가 내보낸617개 metric point cloud만으로 비교했으며, 원본 마스크/카메라 보정/RGB는 다시 검증하지 않았습니다. 이 비교를 전체 촬영 성공이나 cm 정확도 개선으로 해석하면 안 됩니다. 테스트 fixture에는 RGB·원본 마스크 없이 이 회귀 검증용 좌표만 포함합니다. 줄자 정답이 없어 실제 cm 오차 개선 여부는 확인하지 못했습니다.


## 몸판 중심 평면 v4 (현재 앱)

상의의 `armpit_left/right`, `hem_left/right` 네 점으로 몸판 사각형을 잡고, 가로 10–90%·세로 15–85% 구간과 옷 마스크의 교집합에서만 깊이를 수집합니다. 사진의 세로축이 아니라 원본 좌표의 네 점을 사용하므로 옷의 회전에 따라 영역도 회전합니다. 소매·목 주변·밑단 가장자리는 평면 추정에서 제외합니다. 네 점이 누락·비가시·중복이거나 사각형이 교차하면 실패하며 전체 옷으로 되돌아가지 않습니다. 몸판 스키마가 없는 하의·일반 두 점 테스트는 기존 전체 마스크 방식을 유지합니다.

75% 일치율은 이제 선택한 몸판 중심의 유효 표본에 적용합니다. 최소 60개, 10mm 이탈, RMS·공간 분포·범위·시야각 검사는 그대로입니다. 몸판 평면을 확정한 뒤 각 랜드마크의 카메라 광선과 그 평면의 교점으로 치수를 구합니다. 소매의 굴곡을 따라 잰 길이는 아닙니다.

버전은 `garment-plane-4`, 결과는 `garment-plane-neck-perpendicular-mask-4` / `garment-plane-left-neck-vertical-hem-mask-3`입니다. 개발 중 사용한 테스터도 동일한 랜드마크와 영역을 사용했고 JSON `samplingRegion`에 `torsoCenter` 또는 `wholeGarment`를 남깁니다.

|---|---:|---:|---|
| E028772B 검정 패딩 | 314/511 | 76/76 | 평면 통과, 6개 치수 계산 |
| 20DE8888 | 465/617 | 114/118 | 평면 통과, 6개 치수 계산 |

20DE8888의 원본 캡처도 기기에서 추가로 읽어 v4 전체 계산을 재현했습니다. 사용자 캡처는 저장소에 포함하지 않습니다. 표본 영역과 분모가 달라졌으므로 일치율 상승을 cm 정확도 개선으로 해석할 수 없습니다. 검정 패딩의 어깨 등 잘못 잡힌 랜드마크는 이 수정으로 교정되지 않습니다. 줄자와 비교한 정확도 검증은 남아 있습니다.
