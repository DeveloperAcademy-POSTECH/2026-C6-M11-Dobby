# 측정점 보존과 검증 단계 분리

- 작업 브랜치: `fix/64-measurement-angle-stability`
- 검증일: 2026-10-14
- 측정 알고리즘: `lidar-unprojection-1.3.1`
- 인식 진단: `garment-validation-1`

## 문제와 변경 결과

기존 상의 경로는 독립 Vision 마스크와 연결되지 않은 모델 점의 `isVisible`을 false로 만들었다. 목 좌우 점의 표시가 해제되면 파생 목 중앙도 해제됐다. 일반 연결률 75%를 통과하지 못한 원래 방향의 결과보다, 180도 재추론의 완전 연결 결과가 먼저 채택될 수 있었다.

이제 원본 모델 점의 좌표, 신뢰도, 가시성, 파생 관계를 보존한다. 마스크와 연결되지 않은 점은 후보로 남고, 옷 종류 확인과 실제 깊이 지원은 각각 판단한다. 누락된 소매·밑단 점을 새로 만들어 넣거나 경계 밖 좌표를 옷 끝으로 밀지 않는다.

## 1. 독립적인 대상 연결

- `strict`의 기존 75% 기준은 유지한다.
- 같은 방향의 strict 연결만 실패한 경우, 같은 추론·같은 마스크에 `subject` 정책을 적용한다. 추가 모델·Vision 호출은 없다.
- subject 정책도 유효한 같은 좌표계 마스크, 정확히 한 개의 충분한 전경, 신뢰도 0.5 이상인 연결 직접점 3개 이상과 공간 분포를 요구한다.
- subject 연결만으로 옷이라고 결정하지 않는다. 실제 상·하의 기준점과 독립적인 소매·다리 윤곽 근거까지 통과해야 결과를 유지한다.
- 점별 마스크 연결은 `pointAssessments`에 기록한다. `outsideMask`는 실제 가림을 의미하지 않으며, 후보점을 숨기는 명령도 아니다.

상의는 실제 겨드랑이 또는 어깨 쌍, 실제 양쪽 밑단 또는 밑단 중앙과 한쪽 밑단, 몸판 기준점의 독립 윤곽 연결을 확인한다. 점별 0.7과 전체 점 6개 조건을 옷 식별의 일괄 탈락 기준으로 사용하지 않는다. 0.5 미만인 필요한 기준점은 식별 근거로 사용할 수 없다.

몸판 마스크 표본 채움률이 0.75~0.9여도 양쪽 소매 및 옆 틈/아래 소매 근거가 충분하면 `partialSilhouette`로 유지한다. 이 범위는 첫 소프트웨어 회귀 기준이며 실기기 인식률이나 cm 정확도 보장이 아니다. 0.6~0.75의 부족한 몸판은 불확실로 남고, 뚜렷한 비호환 형태는 계속 거부한다.

하의는 실제 허리·가랑이·밑단 기준점과 밑단 밖까지 열린 다리 사이 배경 통로를 유지한다. 치마의 내부 구멍이나 사각형을 바지로 바꾸지 않는다.

## 2. 원래 방향 결과 우선

단독 제공자는 `같은 방향 strict → 같은 방향 subject/옷 구조 → 필요한 경우 180도` 순서다. 원래 방향에서 사용할 수 있는 결과가 나오면 회전 결과로 교체하지 않는다.

자동 분류 제공자는 방향 재시도를 한 곳에서 처리한다. 각 방향의 분류기와 포즈 모델은 정확히 그 방향을 사용하며, 최대 두 방향을 시도한다. 내부 어댑터와 외부 분류기의 중첩 회전 재시도를 제거했다.

여러 의류·여러 충분한 전경·잘못된 마스크/설정·취소는 이 복구로 덮지 않는다. 기존 Vision 전경 개수 제한과 작은 조각 면적 기준은 이번 변경에서 유지한다.

## 3. 치수 계산과 표시

- 점은 사진에서 확인·수정할 수 있다. 표시됐다는 사실만으로 깊이 계산 성공을 뜻하지 않는다.
- 깊이 엔진은 기존 모델 신뢰도 0.5, 센서 깊이 범위·신뢰도·표본 수·분산·국소 평면 지원 조건을 유지한다.
- 깊이에 쓰는 마스크를 확대하거나 구멍을 메우지 않는다. 실제 마스크가 1인 표본만 쓴다.
- 윤곽 연결이 불확실하지만 해당 점 주변에 실제 지원 깊이가 있으면 원래 좌표에서 계산하고 `uncertain`으로 남긴다. 근거가 없으면 해당 치수만 `unavailable`이다.
- 최종 실패 점 ID와 원인을 `MeasurementValue.pointFailures`에 남겨 상세/확인 화면에서 설명한다. 복구에 성공한 총장에는 초기 목점 실패가 남지 않는다.
- 수동으로 지정한 점은 원래 자동 마스크 판정을 현재 실패로 다시 적용하지 않는다.

## 4. 저장·재현

`GarmentLandmarkSet.recognitionDiagnostics`에는 원본 점, 실제 선택 방향, 방향별 추론 시도, 점별 연결 상태, 최종 종류 근거와 분류 점수를 보존한다. 계산용 원본 사진·깊이·최종 마스크는 기존 snapshot/set 계약을 유지한다.

새 set/value 필드는 선택 필드다. 이전 JSON은 새 필드 없이 읽힌다. 수동 보정 후에도 기존 `originalAutomaticLandmarks/Result`에 촬영 당시 자동 근거를 보존하고, 현재 계산은 보정된 점으로 수행한다.

이번 합성/시뮬레이터 검증은 정상 후보점이 코드의 윤곽 검증 때문에 사라지지 않는다는 회귀 근거다. 실제 옷에서 모델이 정확한 위치를 예측하는 비율이나 센티미터 오차를 검증한 것은 아니다.

iPhone 17 Pro에서 문제를 일으킨 긴팔을 다시 촬영하여 원본 점, 점별 윤곽 연결, 실제 선택 방향, 최종 깊이 실패를 함께 비교해야 한다. 사진과 깊이를 먼저 확보하는 촬영 흐름은 유지했으며, 인식 완료를 기다리는 셔터 조건을 추가하지 않았다.
